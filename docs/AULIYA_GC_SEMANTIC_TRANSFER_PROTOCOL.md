# Semantic reference sharing (S1/S2) — registered exploratory protocol

Motivation: native YOLO26-Seg (8.4.210) already learns dense semantic logits in Proto26. Ding et al. (CVPR 2021, Deeply Shape-Guided Cascade) and Shi et al. (Pattern Recognition 2025, DOI 10.1016/j.patcog.2025.111503) motivate cross-task feature transfer, not a claim of novelty. Historical IGEM1 gain on Faruq is not evidence of a semantic-sharing effect.

S0: original completed G1/G2 native RGB YOLO26s-Seg.
S1: native semantic branch unchanged; independent copy of its two reference convolutions, initialized identically to the transferred native trunk. Copy receives O2M classification gradients only.
S2: same native semantic trunk reused by O2M classification and native semantic loss.
Both: same fused P3 input U, same reference trunk architecture, separate zero-initialized 1x1 P3 logit corrections for O2M and O2O, no changes to box/mask outputs at initialization, native loss and mask-aware assignment, O2O reference detached during training. P4/P5 scores unchanged directly. During inference one reference trunk and one residual retained after native fusion; native semantic classifier removed. S1 has more training parameters than S2; matching deployed capacity does NOT isolate semantic loss independently of feature sharing/optimization. Report counts and actual native validation timing (if available); no zero-overhead claim. No IGEM attention, new loss, Haar, MASK2 or augmentation changes.

Preflight: synthetic head tests initial outputs, gradient routing, P3 scope, fusion in both NMS and end-to-end mode; real 21-class official-pretrained model verifies all native initial tensors, native loss components, fused parameter equality S1/S2. No optimization. Both tests and preflight must succeed before training. Notebook defaults AUTHORIZE_TRAINING=False. D1/D2 screening results should be reviewed before activating training.

Same G1/G2 fixed source split, 300 train/75 own eval/75 other eval, seed0, original 80-epoch schedule, official weight SHA, runtime T4 Torch2.11.0+cu130 Ultralytics8.4.210; last epoch80, no cross target validation during training. Baseline references hash/contract checked. B->C first, no A. Report all AP metrics and raw-ranking CSV, original E3 diagnostic protocol (not operational accuracy). S2 screening gates: relative to S0 +2pp cross box18 and hard5 each; worst and mask18 >=-1pp each; within box18 >=-2pp; relative to S1 +0.5pp cross box18 and hard5 each; cross score-selected Top1 (conditional matched anchors, E3 original view) improves for clean18 and hard5. Report bottom3 as secondary; no gate tuning. Rank audit includes all-GT native class-correct at fixed thresholds. If gates pass, repeat on C->B before considering multi-seed confirmation and locked A; neither B nor C development is independent test. Otherwise stop S2 v1; no automatic architecture/loss sweep. Single-seed exploratory thresholds are not statistical significance. Resume native not bit identical.

No training results at registration. Code must be validated on actual pinned runtime; local environment does not contain Ultralytics.

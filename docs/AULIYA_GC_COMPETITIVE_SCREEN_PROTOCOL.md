# M1/M2 competitive supervision — registered screening protocol

## Motivation and scope
E1/E3 results support candidate ranking as a first intervention hypothesis, not proof of a loss defect. Stop general-purpose diagnosis. No architecture, preprocessing, assignment, augmentation, or inference changes. M0 is the two completed native RGB G1/G2 runs. Test A remains locked.

## Mechanism
For each GT g with nonempty native O2M foreground set P_g, let a^- be the anchor whose strongest non-GT logit is largest within P_g, and c^- that competing class. M1 uses z[a^-, y_g] as the positive reference (same-anchor control). M2 uses max_{a in P_g} z[a,y_g] as the positive reference (cross-anchor). Both use exactly z[a^-,c^-] as the negative reference, margin 1.0, softplus(margin+negative-positive), mean over represented GTs. Stable first-index tie-breaking for anchors. The positive and negative selections are detached; gradients flow through the selected logits. Empty foreground returns differentiable zero. Both arms have identical hard reduction and object normalization; the only intended contrast is selection of the true-class anchor. M1 is a hard same-anchor control, not an average of per-anchor margins. Native foreground includes anchors whose target score can be zero. No GT used at inference.

Add 0.25 * batch_size * mean_aux to the classification component of the native batch-scaled dual-head loss vector. Fixed auxiliary weight is outside the native O2M/O2O decay. Native classification BCE, mask-aware assignment, box, mask, DFL and semantic objectives and native branch weights are unchanged. The auxiliary gradient uses O2M logits only; backbone gradients are allowed through O2M. Actual assignments can diverge during learning because the models evolve, not because the assignment rule changes. No extra trainable or inference parameters. Same nominal epoch/data/optimizer budget, not equal wall time. Native training loss log reports O2O; auxiliary telemetry logged separately for every epoch. No cross-group data used during training.

## Runs and safeguards
Train M1-B, M1-C, M2-B, M2-C from official pretrained SHA, fixed 80 epochs, seed 0, same split and schedule as G1/G2. Strict original report/checkpoint references, split, torch, GPU and Ultralytics runtime match. T4, single GPU, original report torch 2.11.0+cu130, Ultralytics 8.4.210. Preflight verifies exact initial state dict parity among M0/M1/M2, real model synthetic native loss components and auxiliary logit gradient. Five unit tests cover mathematical loss and grouping; Kaggle runs them plus historical tests before training. Checkpoints published and hashed each epoch; evaluate exact last.pt epoch 80 on both development targets. Original-view E3 ranking audit on both targets, same IoU .75, with per-instance CSV. Preserve all per-class box/mask AP. No target validation during training. Resume from published pair only; native EMA checkpoint resume is not bit-identical to uninterrupted training and must be reported.

M2 versus M1 mean cross Macro18 and Hard5 each >=0.5 pp. Mean cross Mask18 must not regress; mean cross score-selected top1 (clean18 and hard5) must improve over original-view E3 M0.

# Bibliography Metadata Lock — Proposal

Status: **ACTIVE HARD GATE — CURRENT FORMAL SET**

Dokumen ini mengunci metadata bibliografis untuk sumber yang benar-benar disitasi pada artefak formal di `docs/thesis/proposal/`. Metadata tidak boleh dilengkapi dari ingatan atau aggregator ketika sumber resmi/primer tersedia.

## Aturan

1. `LOCKED` berarti metadata yang diperlukan untuk entri bibliography telah diperiksa pada sumber resmi/primer.
2. `PREPRINT LOCKED` berarti versi primer yang digunakan adalah preprint dan harus ditulis transparan sebagai preprint.
3. Satu paper hanya menggunakan satu konvensi bibliografis yang konsisten; jangan mencampur halaman/DOI dari representasi publisher yang berbeda.
4. Hanya sumber yang benar-benar disitasi pada BAB I–III yang masuk `DAFTAR_PUSTAKA.md`.
5. Sumber backend yang telah diverifikasi tetapi tidak disitasi tetap disimpan pada audit sumber, bukan pada bibliography formal.

# Thesis Proposal Foundation — v0.13.0

Date: 2026-08-25

Milestone: **reproducible Git-driven DOCX/PDF working assembly**.

## Added

### Executable proposal builder

`tools/thesis/build_proposal_docx.py`

The builder now assembles Bab I–III directly from the repository sources and enforces the modular replacements already frozen by the audits:

- normalized §2.2;
- normalized §2.9 related-work table;
- primary-source-hardened §3.5 AF2 methodology.

Internal citation keys are converted to working author-year citations so repository-only source keys do not appear in the review DOCX.

### GitHub Actions document build

`.github/workflows/build-thesis-proposal.yml`

The workflow produces:

```text
Proposal_AF2_USU_Working.docx
Proposal_AF2_USU_Working.md
Proposal_AF2_USU_Working.pdf
```

The PDF is a render-review artifact; the DOCX is the editable working review artifact.

### Build-pipeline contract

`docs/thesis/foundation/10_PROPOSAL_BUILD_PIPELINE.md`

The contract freezes:

```text
Git scientific content
-> deterministic assembly
-> campus-format working DOCX
-> PDF render
-> visual QA
-> review/release
```

and records what is still required before a file can be labelled final/submission-ready.

## Current formatting scope

The working builder applies:

- A4;
- Times New Roman 12 pt;
- 1.5 body spacing;
- 1.27 cm first-line indent;
- margins 4 cm left and 3 cm top/right/bottom;
- Word heading hierarchy;
- editable Word tables;
- Pandoc-converted native equation objects where supported;
- generated TOC;
- working page numbering.

## Not yet final

The generated artifact must **not** yet be called a sempro-final/submission document. Remaining gates include:

1. exact USU cover/front-matter reproduction;
2. Roman-vs-Arabic page-number sections according to the official guide;
3. Figures 3.1–3.4 insertion;
4. table continuation / landscape audit;
5. chapter-based equation numbering and source labels;
6. final APA metadata normalization;
7. reference-count / journal-percentage audit where applicable;
8. page-by-page visual QA of the rendered Word document.

No new experiment is introduced by this milestone.

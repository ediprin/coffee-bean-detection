# Thesis Proposal Foundation — v0.14.0

Date: 2026-08-25

Milestone: **formal-assembly static QA + QA-hardened working builder**.

## What changed

### 1. Formal assembly audit added

Created:

`docs/thesis/sources/PROPOSAL_ASSEMBLY_QA_2026-08-25.md`

The audit distinguishes scientific-content readiness from campus-layout readiness and records explicit blockers rather than calling the first generated Word file final.

Major open release gates remain:

- template-faithful final generation;
- formal front-matter/body pagination;
- landscape decision for wide Table 2.1;
- chapter-based equation numbering;
- actual render-to-PNG inspection of every page.

### 2. QA-hardened builder added

Created:

`tools/thesis/build_proposal_docx_v2.py`

The v2 builder now:

- supports optional `--reference-doc` for a supplied campus DOCX scaffold;
- removes working Markdown horizontal rules;
- removes fenced-code delimiters to avoid accidental monospaced blocks;
- converts unordered Markdown bullets to ordered lists for formal assembly;
- converts table-title headings to ordinary table-caption paragraphs so they do not enter the TOC;
- normalizes table-caption punctuation (`Tabel x.y  Judul`);
- merges adjacent author-year citation groups generated from adjacent internal keys;
- fails if a used citation key has no bibliography record;
- fails if internal citation tokens survive assembly;
- warns when the current cited-source count remains below the final program reference-count requirement rather than padding references artificially;
- splits chapter headings into the campus-style two-line form (`BAB I` / `PENDAHULUAN`);
- relaxes the previous blanket 9-pt table formatting and reserves stronger compaction for wide tables.

### 3. Citation-integrity corrections applied in the builder

Primary-PDF evidence overrides older ad-hoc metadata for:

- `COF-10` de Oliveira et al.: DOI corrected to `10.1016/j.jfoodeng.2015.10.009`;
- `COF-17` García et al. 2019: complete working bibliography record added with DOI `10.3390/app9194195`.

The older master-map DOI discrepancy for de Oliveira is now documented as a registry-maintenance issue rather than silently propagated.

### 4. Figure-caption formatting normalized

Updated:

`tools/thesis/insert_proposal_figures.py`

Captions now use:

- no period after the figure number;
- no terminal period;
- title case;
- Times New Roman 12 pt;
- centered placement below the figure;
- 13.5 cm working image width for additional margin tolerance.

### 5. CI build route updated

Updated:

`.github/workflows/build-thesis-proposal.yml`

CI now calls `build_proposal_docx_v2.py` before inserting Figures 3.1–3.4 and rendering a PDF working artifact.

The CI build remains explicitly a **working build** because the binary campus template is not stored in the repository and the formal pagination/landscape/equation-number gates have not yet been closed.

## Scientific consequence

No ML method, dataset split, result, or training protocol changed in this milestone. This is document-engineering hardening only.

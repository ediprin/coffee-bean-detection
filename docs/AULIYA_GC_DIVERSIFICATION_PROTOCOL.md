# D1/D2 — literature-control screening

Motivation: negative OCCS result (STOP_OCCS_V1), not a new contribution.
Sources: Ghiasi et al. CVPR 2021 (Simple Copy-Paste); Lee et al. AAAI 2024 DOI 10.1609/aaai.v38i4.28076, OA-DG code ba6d86e86c65fa9c315c256b79d39cd325f5083d. Ultralytics v8.4.210 native augmentation code. D0 original RGB G1/G2 completed.

D1: native YOLO cross-image CopyPaste mode mixup, p=.5 (both application probability and eligible-object fraction). Same native mosaic/HSV/perspective/flip etc. Not exact Ghiasi recipe (different detector, scale policy and overlap rule). May generate unnatural arrangements or occlusion; not certified label preservation. Native close_mosaic disables CopyPaste for final 10 epochs.

D2: restricted one-view photometric adaptation of OA-Mix, p=.5 after native transforms, before Format. Width3 Dirichlet mixtures, depth1–3, 1–2 local regions with area .01–.1, aspect ratio 1/3–3, original vs augmented beta mixing, low-saliency region weight <=.5 (threshold10 on 0–255 mean spectral residual map), 1–5 random regions area .005–.1, smoothed box masks. Changes from paper: only color/contrast/brightness/sharpness factors .8–1.2 (not original severity10, no posterization/solarization/inversion/geometric local warps); portable spectral residual approximate implementation; normalized convex overlap weights; one view, no OA-Loss, no additional optimizer exposures. These decisions preserve polygon coordinates, not necessarily fine-grained class identity. Native close_mosaic rebuild removes D2 at final 10 epochs. No D3 yet. Both controls keep native model/criterion and inference. Training pipeline checked at startup and small source-only preview exported. Same p does not mean equal perturbation strength or object count.

Training: B source 300 images, B/C evaluation 75 each; original fixed split digest and official pretrained SHA, seed0, 80 epochs, same schedule except explicit copy_paste config for D1/D2. Original T4, Torch 2.11.0+cu130, Ultralytics8.4.210. No A access. No cross target validation during training; evaluate last epoch80 on both. D0 B->C box18 44.386%, hard5 36.433%, bottom3 23.630%, worst15.063%, mask18 38.914%; B->B box18 91.609%.

Exploratory B->C gate: +2 pp each box18 and hard5, worst >= baseline-1pp, mask18 >= baseline-1pp, B->B box18 >= baseline-2pp. Report all metrics, including bottom3 and per-class AP. If a control passes, verify on C->B using same settings (not independent test); if both fail, do not sweep augmentation knobs or invent D3 on this evidence. A successful control is not novelty; investigate specific mechanism before proposing D3. Single seed/limited support, no causal proof of acquisition component. Preserve report-only and full output checkpoints; native resume not bit-identical.
